# 📈 Auto Trading Signal Generator & Tracker

Автоматический консольный трекер и генератор торговых сигналов для фондового рынка, написанный на C# и .NET. 

Программа в реальном времени анализирует изменения цен акций, рассчитывает торговые сигналы (BUY / SELL / HOLD) на основе дневных колебаний и автоматически обновляет историю в CSV-отчете без дублирования данных.

 🚀 Основные возможности

  Автоматический трекинг: Сканирует текущие цены и дописывает новые данные в файл (trading_signals.csv) в режиме append.
  Защита от дубликатов: Проверяет дату перед записью — повторные запуски в один день не дублируют строки.
  Генерация сигналов:
    🟢 BUY (Покупка): при росте цены более чем на +1.5%
    🔴 SELL (Продажа): при падении цены более чем на -1.5%
    ⚪ HOLD (Удержание): при колебаниях в пределах ±1.5%
 Выгрузка отчетов: Сохраняет всю историю в структурированный CSV-файл для дальнейшего анализа в Excel.
